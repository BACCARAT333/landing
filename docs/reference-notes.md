# Референс и план лендинга

## Референс
Стиль: минималистичный SaaS-лендинг (в духе популярных макетов на Behance/Pinterest
по запросу "landing page", "hero section", "one page website") — светлый фон,
тёмная кнопка CTA, крупный заголовок по центру, сетка карточек с иконками.

(Сюда нужно добавить скриншот выбранного референса, например reference.png)

## Список секций
1. Header — логотип, навигация по якорям, кнопка CTA
2. Hero — заголовок, подзаголовок, две кнопки (основная и второстепенная)
3. Features — заголовок секции + сетка из 3 карточек с иконкой, названием и описанием
4. Footer — копирайт и ссылки

## Цветовая палитра
- Фон: #ffffff (основной), #f7f7f8 (hero-секция)
- Текст основной: #1f1f1f
- Текст вторичный: #5a5a5a
- Акцент / кнопки: #1f1f1f (фон), #ffffff (текст)
- Рамки / разделители: #eaeaea

## Шрифты
- Системный шрифтовой стек: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto,
  Helvetica, Arial, sans-serif
- Заголовок Hero: 3rem / 700
- Заголовки секций: 2.25rem / 700
- Основной текст: 0.95–1.1rem / 400
